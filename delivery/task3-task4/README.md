## 如何下载

1. 打开本仓库：https://github.com/mengxiongtaiyi/spider  
2. 进入目录：`delivery/task3-task4/`  
3. 点击右上角绿色 **Code → Download ZIP** 下载整个仓库；或只下载本目录可用 [Download Directory](https://download-directory.github.io/) 粘贴本文件夹 URL。  
4. 也可：`git clone https://github.com/mengxiongtaiyi/spider.git` 后打开 `delivery/task3-task4/`。

图片已包含在各任务的 `images/` 子目录中，无需另行索取。
